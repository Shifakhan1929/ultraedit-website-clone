# UltraEdit Website Clone

A frontend recreation of the UltraEdit website built using **HTML5 and CSS3**. This project focuses on recreating the website's layout, navigation, download sections, language selection cards, and overall user interface.

## 🌐 Project Overview

This project is a practice implementation inspired by the official UltraEdit website. It helped me explore webpage structuring, styling techniques, responsive layouts, Flexbox, and CSS Grid.

## ✨ Features

- Responsive navigation bar.
- Hero section with download call-to-action.
- Language selection cards.
- Download information section.
- Newsletter subscription UI.
- Footer with navigation links.
- CSS-based layouts using Flexbox and Grid.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, and responsiveness.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Shifakhan1929/ultraedit-website-clone.git
```

**2. Navigate to the project directory**

```bash
cd ultraedit-website-clone
```

**3. Open the website**

Open `index.html` in your browser.

Alternatively, use the Live Server extension in VS Code.
